Salary Engine Execution Flow

Every salary group is evaluated top-to-bottom across 4 sequential stages during payroll calculation.

01 Pre-Balancing
Top-to-Bottom Order

Lines evaluate strictly sequentially. A formula can reference any component line placed above it.

HRA = BASIC * 0.4
02 Gross Resolution
Gross Computation

Right before the Balancing line, the engine automatically resolves gross earnings from monthly CTC:

GROSS = CTC − Employer Contrib
03 Balancing Line
Balancing Remainder

The designated Balancing line takes whatever is left so earnings add up to Gross (or CTC).

Special Allw = Remainder
04 Post-Balancing
Gross-Dependent Lines

Lines placed below Balancing execute last. Put deductions needing finalized GROSS here.

ESI_EE = GROSS * 0.75%
Value Engine

Formula (Numeric Amount)

Determines how much the component pays or deducts. Evaluates arithmetic expressions, variables, and statutory rates.

EXAMPLE FORMULA
BASIC * 0.4
Sets HRA to exactly 40% of the employee's calculated Basic pay.
Eligibility Gate

Condition (Gatekeeper)

Determines whether the line item triggers at all. If empty, it always runs. If false, the line becomes ₹0.

EXAMPLE CONDITION
GROSS <= ESI_LIMIT
Employee ESI only applies if Gross earnings do not exceed ₹21,000 threshold.
