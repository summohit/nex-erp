Cost projects from approved time only

When on, only timesheet days a project manager has approved count toward project cost. When off, every logged hour counts except days that were explicitly rejected.

Leave this off unless timesheets are actually being reviewed. Turning it on re-prices every project against approved days only — hours nobody has got round to approving stop counting, and project cost drops accordingly. Project cost now counts approved days only. Any project whose time has not been reviewed will report a lower cost than the work it actually took.

How Distance & Claims are Processed

Technicians record GPS coordinates when tapping Start Journey and End Journey in the mobile app. The hourly system sweep calculates round-trip kilometers, multiplies by the assigned vehicle rate, and submits a formal expense claim to Finance for reimbursement.

Changes take effect on all completed field visits in the next hourly sweep.

Require Two-Factor Authentication

Every user must set up an authenticator app before they can sign in. Anyone without one is walked through setup at their next login.

Set up two-factor on your own account first — the server refuses to turn this on otherwise, because a SuperAdmin without an authenticator would lock the whole company out. Nobody can disable their own second factor while this is on.
