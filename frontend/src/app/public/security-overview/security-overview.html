Enterprise Trust & Security

Security Overview

Effective Date: September 8, 2026

Built for Enterprise Reliability & Compliance

Security is embedded into every architectural layer of NEX ERP. From end-to-end data encryption and strict role isolation to automated audit trails, we ensure your organization's sensitive operational data remains fortified.

01

Data Encryption Architecture

We enforce multi-tiered cryptographic controls across data lifecycle transitions:

  • Encryption in Transit: All communication between client applications (web, iOS, Android) and our cloud services is enforced through modern TLS 1.3 encryption (HTTPS/WSS) with strict cipher suite configurations.
  • Encryption at Rest: All core databases, transactional logs, and object attachments are encrypted using industry-standard AES-256 bit encryption algorithms.
  • Cryptographic Password Hashing: User credentials are protected using salted, computationally intensive hashing algorithms (Bcrypt/Argon2). We never store or transmit plaintext passwords.
02

Role-Based Access Control (RBAC) & Multi-Tenancy

NEX ERP utilizes strict multi-tenant logical partitioning to guarantee that company records are completely isolated and impenetrable by unauthorized users:

  • Organizational Sandboxing: Every database query is scoped strictly to your unique company identifier, preventing cross-tenant data leakage.
  • Granular Permissions: Access rights are governed by fine-grained permissions. Standard employees cannot access confidential salary structures, peer appraisals, or administrative configurations without explicit privilege delegation.
  • Session Authentication: Stateful verification with JSON Web Tokens (JWT), automatic token invalidation upon password reset, and configurable inactivity timeouts.
03

Cloud Infrastructure & Network Defense

Our microservices and application gateways operate on top of hardened tier-1 cloud facilities:

  • Distributed Denial of Service (DDoS) Mitigation: Automated edge traffic analysis and scrubbing networks absorb and neutralize high-volume attacks.
  • Virtual Private Clouds (VPC): Databases and internal message brokers reside inside isolated private subnets inaccessible from the public internet.
  • Continuous Patching: Operating system kernels, Docker containers, and framework dependencies undergo regular patch cycles to address upstream zero-day CVEs.
04

Mobile App Security & Geolocation Integrity

The NEX ERP mobile application incorporates specialized device safeguards:

  • Anti-Tampering & Mock Detection: Geolocation verification checks defend against mock locations and GPS spoofing during punch-in/attendance submissions.
  • Minimal Permission Footprint: We request only runtime permissions necessary for functionality (such as camera for document uploads or receipt capture). We do not perform silent background tracking.
  • Secure Local Storage: Sensitive device tokens are safeguarded in encrypted hardware-backed keystores (Android KeyStore and iOS Keychain).
05

Comprehensive Audit Logging & Forensics

To assist your internal compliance and forensic investigations, NEX ERP captures tamper-resistant audit logs:

  • All administrative modifications (salary overrides, employee terminations, role promotions, and record deletions) record user timestamps and originating IP addresses.
  • Access logs are preserved in append-only storage systems, preventing deletion even by standard administrators.
06

Backup, Disaster Recovery & Resilience

Business continuity is built into our operational roadmap:

  • Automated Daily Snapshots: Encrypted backups of all production relational databases occur on an automated daily schedule with point-in-time recovery capabilities.
  • Geographic Redundancy: Backups are replicated across independent availability zones to safeguard against localized datacenter failures.
